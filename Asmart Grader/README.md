# Smart Grader

أداة تصحيح أوراق الاختيار من متعدد (OMR) — تعمل بالكامل داخل المتصفح.
لا Backend، لا Database، لا CDN، لا خدمات خارجية، لا حفظ دائم (Refresh = جلسة جديدة).

## الملفات
- index.html  → البرنامج كامل (UI + CSS + JS في ملف واحد)

## التشغيل
- افتح index.html مباشرة، أو ارفعه على أي استضافة ملفات عادية.
- لا يوجد أي طلب شبكة أثناء التشغيل → يعمل بعد انقطاع الإنترنت.

## ملاحظة الكاميرا (للمرحلة التالية)
الكاميرا تحتاج HTTPS أو localhost. بدونها استخدم زر "رفع صورة".
